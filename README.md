# virtual_gamepad

A highly responsive, reusable virtual gamepad UI package for Flutter. 

This package provides a complete, drop-in on-screen gamepad interface that translates user interactions (joystick movements, D-pad presses, and action buttons) into a standard **8-byte HID Gamepad state array**. It is designed for developers building remote play, game streaming, or Bluetooth HID controller applications.

## Features

- 🎮 **Complete Gamepad UI**: Includes dual analog sticks, a D-Pad, 4 action buttons (A, B, X, Y), 4 shoulder buttons (L1, R1, L2, R2), and 3 menu buttons (Select, Start, Back).
- ⚡ **Zero-Latency State Generation**: Rapidly converts screen touches into a highly optimized `Uint8List` byte array (8 bytes total) representing standard USB HID gamepad data.
- 🎯 **HTML5 / Linux Evdev Standard Mapping**: The generated byte array perfectly maps to the standard Linux Generic Gamepad schema, enabling flawless compatibility with the HTML5 Gamepad API and generic game engines.
- 🎩 **Proper Hat Switch Support**: D-Pad inputs are automatically converted into an 8-way Hat Switch value (0-8) natively within the byte array.

## Installation

Add `virtual_gamepad` to your `pubspec.yaml` dependencies:

```yaml
dependencies:
  virtual_gamepad: ^1.0.0
```

## Usage

Using `virtual_gamepad` is incredibly straightforward. Simply drop the `GamepadView` widget into your layout and listen to the `onGamepadData` callback.

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:virtual_gamepad/virtual_gamepad.dart';

class MyGamepadScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // GamepadView renders the entire controller UI
      body: GamepadView(
        onGamepadData: (Uint8List data) {
          // 'data' is the 8-byte HID array representing the current controller state.
          // Example: Send this data over a Bluetooth MethodChannel to your native platform!
          print("Gamepad state updated: \$data");
        },
      ),
    );
  }
}
```

### The 8-Byte HID Payload Structure

Every time the user interacts with the UI, `onGamepadData` emits an 8-byte `Uint8List` formatted as follows:

| Byte | Purpose | Details |
|------|---------|---------|
| **0** | Primary Buttons | Bits 0-7: A, B, X, Y, L1, R1 |
| **1** | Secondary Buttons | Bits 0-4: L2, R2, Select, Start, Mode |
| **2** | Padding | Unused (Padding for 24-button layouts) |
| **3** | Hat Switch | Lower 4-bits represent 8-way D-Pad (0=Null, 1=Up, 2=UpRight, etc.) |
| **4** | Left Stick X | Int8 (-127 to 127) |
| **5** | Left Stick Y | Int8 (-127 to 127) |
| **6** | Right Stick X | Int8 (-127 to 127) |
| **7** | Right Stick Y | Int8 (-127 to 127) |

*Note: For the Native platform descriptor matching this payload, check out the example directory in the repository.*
